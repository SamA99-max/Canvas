# Canvas
This is a python code for a Air Canvas using cv2, mediapipe, numpy, time and maths

This project tracks the hands of the user especially the fingers and either draws a line or selects colors and eraser.
Make sure you have the mediapipe version : 0.10.14 for that you will need python version 3.8-3.12
I will recommend Cv2 version 5.0.0, python version 3.12.9 and numpy version 1.26.4 as i coded this file in these versions
